常用型号写法

  • 漏电断路器：DZ47LE-63 C32 30mA＝带 30mA 漏电保护的 32A C 型开关（正泰 NXBLE、德力西 DZ47sLE）。
  • 漏电附件：Vigi iC65 30mA 拼装在普通微断右侧，组成"空开 + 漏保"。
  • 极数：单相支路用 1P+N 或 2P；单相总开关用 2P；三相动力用 3P，混有单相负载时用 4P / 3P+N。
选型基本式：Ib ≤ In ≤ Iz
Ib 实际计算电流 ≤ In 断路器额定电流 ≤ Iz 电线允许载流量，且断路器需在 1.45×Iz 内动作； 压降一般不超过 5%。本工具即按此规则计算。
